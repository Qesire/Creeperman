## 本次做了什么核查

- 读取主任务书和更新日志正文，以及任务指南、方法汇总、ISC 说明与报告、计算器 README/源码/模型。
- 对最新门槛、计数单位、证据规则、扩展年份和包装要求交叉核对；独立复核了问题定义中的集合与计分含义。
- 对六年基线执行只读流式扫描，检查归一化排序、相邻重复、正则结果、末尾 TLD 聚合与文件哈希；排序检查通过时，相邻去重才可替代全量集合去重。详细范围与输出见[基线审计](BASELINE_AUDIT.md)。
- 使用 1996 年前 100,000 行对比官方集合算法和流式汇总，并以合成输入检查大小写、空白、www 变体、无权重 TLD、非法 URL 和语义异常。
- 核对 ISC 报告 `48 / 1800 = 2.6667%` 的算术与查询口径；未重新执行其网络实验。报告引用的原始 CSV、样本清单及日志位于任务包之外，本次 ISC 子目录不包含这些材料。
- 访问 W3C、CERN 及明尼苏达大学的公开资料入口。明尼苏达大学的[数据集记录](https://experts.umn.edu/en/datasets/link-lists-for-websites-tracking-the-development-of-the-early-web/)确认 DOI `10.13020/D62684` 对应 1996—2000 年网站链接数据，公开描述包含 source、destination、frequency 等字段；本次未下载并审核其底层逐条年份证据。其他入口和观测边界见[开放研究问题](OPEN_RESEARCH_QUESTIONS.md)。
